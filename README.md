# Program Kursus Online "Ganebo"

Program Kursus Online "Ganebo" merupakan aplikasi berbasis **console** yang dibuat menggunakan bahasa pemrograman Python untuk mengelola proses pendaftaran kursus online.

Program ini memungkinkan pengguna untuk melakukan input data siswa, memilih paket kursus, menghitung total biaya, menghitung uang kembali, serta melakukan transaksi secara berulang sesuai kebutuhan.

---

## Fitur Program
- Input data siswa
- Pemilihan paket kursus (Cerdas, Ceria, Smile)
- Perhitungan total biaya
- Perhitungan uang kembali
- Transaksi berulang

---

## Paket Kursus

| Kode | Nama Paket | Materi               | Harga      |
|------|------------|----------------------|------------|
| 1    | Cerdas     | Android Programming  | 3.000.000  |
| 2    | Ceria      | Desain Grafis        | 2.500.000  |
| 3    | Smile      | Multimedia           | 2.000.000  |

---

## Cara Menjalankan Program

Pastikan Python sudah terinstal di komputer, kemudian jalankan perintah berikut melalui terminal atau command prompt:

```bash
python program.py
```
